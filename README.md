# ملاذ — موقع إحصائيات مجتمع Discord

واجهة عربية RTL فاخرة وجاهزة للنشر على Vercel. النسخة الحالية Frontend ثابتة وتعمل ببيانات تجريبية داخل `app.js`.

## التشغيل

يمكن فتح `index.html` مباشرة، أو نشر المستودع على Vercel كـ Static Site:

1. Import repository في Vercel.
2. Framework Preset: **Other**.
3. Build Command: اتركه فارغاً.
4. Output Directory: `.`.
5. Deploy.

## تنبيه أمني مهم

لا تضع Discord Bot Token أو Client Secret داخل `index.html` أو `styles.css` أو `app.js`. هذه الملفات تصل إلى كل زائر. ربط البوت الحقيقي يحتاج Backend منفصلاً مع قاعدة بيانات وDiscord OAuth2 للوحة الإدارة فقط.

## الخطة المقترحة للنسخة الحقيقية

- الموقع العام: قراءة وبحث فقط وبدون تسجيل دخول.
- `/admin`: تسجيل Discord OAuth2 للمالك فقط.
- Backend يحفظ التوكن في متغيرات البيئة ويجلب الرتب والإحصائيات.
- قائمة `visibleRoleIds` تحدد الرتب والأعضاء التي تظهر للعامة.
- لا يتم إرسال الرتب المخفية إلى API العام أصلاً.

البيانات التجريبية موجودة في بداية `app.js` ويمكن استبدالها لاحقاً بطلبات `fetch('/api/...')`.
